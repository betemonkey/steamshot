# Steamshot icon

- `steamshot.svg`: the icon (drawn in Steam's style: round badge, navy-to-blue gradient, white mark; it does not use Valve's logo).
- `steamshot-small.svg`: the same icon with thicker lines, used for 16-24 px and the browser tab.
- `steamshot.ico`: Windows icon with every size from 16 to 256 px (bold variant below 32 px).
- `steamshot-256.png`: the 256 px frame on its own.

The dashboard serves `steamshot.ico` as `/favicon.ico` and `steamshot-small.svg` as `/icon.svg`.
